# PMersion holding page

Temporary public landing page for `pmersion.com` while the V1 product remains under development in governed Preview/Staging environments.

- Static only
- No analytics
- No cookies
- No authentication
- No backend
- No production SaaS traffic

Brand baseline: navy `#0B1D3A`, blue `#1967D2`, teal `#00A8B5`.

This repository is intentionally separate from the private PMersion application repository.
